# Interactive Quiz Application

A responsive browser-based quiz application with multiple-choice questions, instant feedback, a score summary, and a restart option.

## Technologies
- HTML5
- CSS3
- JavaScript (vanilla)

## Features
- Multiple-choice questions.
- Immediate correct/incorrect feedback.
- Progress indicator.
- Final score and performance message.
- Restart quiz button.
- Responsive layout for desktop and mobile.
- No build tools or external libraries required.

## Run locally
Open `index.html` in a modern browser. For a local development server, use VS Code Live Server or run:
```bash
python -m http.server 8000
```
Then open `http://localhost:8000`.
